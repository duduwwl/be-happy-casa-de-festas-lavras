# Be Happy Casa de Festas

Landing page da Be Happy Casa de Festas, em Lavras (MG), com galeria de cenários reais, formulário de consulta via WhatsApp, localização e links para Instagram.

## Publicação

O site é estático e fica em `dist/`. O workflow em `.github/workflows/pages.yml` publica automaticamente essa pasta no GitHub Pages a cada atualização da branch `main`.

As imagens da galeria foram selecionadas do material fornecido pela Be Happy e do perfil público oficial `@behappy_casadefestas`.
